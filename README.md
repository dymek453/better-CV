# better-CV
Prosty, szybki i intuicyjny kreator CV. Aplikacja pozwala na wybranie jednego z gotowych szablonów, wygodne uzupełnianie danych w formularzu oraz podgląd zmian na żywo. Gotowy życiorys można jednym kliknięciem wyeksportować do pliku PDF.

## Główne funkcje
* **Prosty proces:** Landing page -> Wybór szablonu -> Edytor CV.
* **Podgląd na żywo:** Tekst wpisywany w formularzu natychmiast pojawia sie na dokumencie.
* **Wielojęzyczność:** Wbudowany prosty mechanizm zmiany języka interfejsu (PL / EN).
* **Standaryzacja:** Gotowe listy rozwijane (np. poziomy znajomości języków obcych od A1 do C2).
* **Eksport PDF:** Zapisywanie gotowego CV bezpośrednio na dysk komputera.

## Technologie
* **Frontend:** React + Vite
* **Zarządzanie stanem** Wbudowane context API oraz `useState`
* **Zarządzanie projektem:** Jira (tablica Kanban)
